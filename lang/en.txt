# QpdfDesk — English, the reference catalog: every text the program shows.
#
# key = text
#   {name}   a value the program fills in; keep every one, in any order.
#   \n       a line break.
#   key.one / key.few / key.many — the forms of a count: one (1), few (2–4,
#            22–24… — Polish), many (the rest). English has no `few`.
#
# A translation is lang/<code>.txt with the same keys; a key it leaves out
# shows in English. Never use @ (FLTK draws a symbol) nor & (a button's
# keyboard shortcut; only step.* may); in item.* (drop-down and menu entries)
# never | / or _. The build checks all of this.
